# Art direction studies

An art bible is a compact set of visual promises: palette, shape, material, lighting, motion, and legibility rules. There is one per style here so each direction can be judged as a coherent whole rather than as an isolated attractive image.

- **Signal Print** — crisp instructional screenprint with warm paper and decisive silhouettes.
- **Fired Workshop** — glazed ceramic and darkened brass made tactile by warm raking light.
- **Night Current** — a spacious dark field whose state is carried by precise colored light.
- **Field Notes** — graphite, colored pencil, cut paper, and visible working revisions.

Each folder contains four concept images, two restyled shots of the real toy with their sources, a presentation sheet, and `prompts.txt`. Regenerate an image with the Codex built-in image tool using its recorded prompt; the kept candidate and tool mode are recorded alongside it.

None of these directions is selected. The choice belongs to the owner.
