`nix-shell --run 'cargo run -- --gallery .gallery/run-1'` creates a new headless gallery at native pixel size, a single `sheet.png`, individual scene images, mechanical results, and `hashes.txt`. Use a new directory for each run. Scratch lives under ignored `.gallery/`; only `gallery/hashes.txt` is a committed baseline.

`cargo test -- --test-threads=2` does the same work under `.gallery/test`, renders the complete sequence twice in one renderer, and requires identical pixels and the reviewed hashes. Palette backgrounds are captured with the pictures hidden, so the contrast and silhouette gates measure the final composited pictures against their actual plates. The arm strip contains every captured frame in reading order without rescaling. The ghost scene places live and projected frames side by side. Every atom kind and every machine kind comes from its existing enumeration.

Run `nix-shell --run 'gallery/critic.sh .gallery/test'` after a changed-frame failure. It consumes that exact gallery, verifies each image hash, and starts a fresh read-only critic only for scenes absent from the baseline or with changed hashes. The fixed rubric is `gallery/RUBRIC.md`. Every score must be at least eight. A cached judgement, including a failing one, is reused until its scene or rubric changes. The script never edits the baseline; copy `approved-hashes.txt` and repeat the tests. Include changed scene scores in the landing comment, or `gallery unchanged` when there are none.
